## Language Copies e Translation Integration

- **Language Master**: O ramo principal de páginas criado no idioma de origem.

- **Translation Integration Framework (TIF)**: Conecta o AEM a provedores de tradução humana ou máquina (_Machine Translation_).

- **Automação**: O AEM gera projetos de tradução automatizados que enviam e reimportam o conteúdo traduzido para criar as **Languages Copies**.
