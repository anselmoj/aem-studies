## Core components Introduction

Os Core Components sao um conjunto de componentes padronizados (como botão, accordion, carrossel, container,) de Gerenciamento de Conteúdo Web (WCM) para o AEM, projetados para acelerar o desenvolvimento e reduzir custos de manutenção nos sites.

### Conjunto de componentes

- Container Components: Inclui o **Container de Layout** e **Carrousel**, além de **Tabs** e **Accordion**.
- Page Authoring Components: Inclui o **Button**, junto com o **Title**, **Text**, **Image**, **Teaser** e **Content Fragment**.
- Form Components: Contem toda a estrutura de **Forms**, como o **Form Container**, **Form Text**, **Form Options**, **Form Hidden** e **Form Button**.

### Divisão de **"Core Structure"** e **"Core Content"**

O AEM separa os componentes entre estrutura base do template e conteúdo inserido pelo author nas páginas.

- Template Components: Sao os componentes estruturais como **Page**, **Navigation**, **Language Navigation** e **BreadCrumb**, eles formam o esqueleto da página.
- Page Authoring Components: Sao os componentes que os autores usam diretamente para preencher a pagina de conteúdo e informações, como **Title**, **Text**, **Image** e **Teaser**.
